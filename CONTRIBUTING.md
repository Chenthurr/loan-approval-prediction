# Contributing

This project demonstrates an end-to-end synthetic loan-risk ML pipeline.

## Guidelines

- Keep the dataset explicitly synthetic and avoid introducing real applicant data.
- Add regression tests for preprocessing, feature engineering, prediction, and evaluation changes.
- Use the fixed random seed when reproducibility matters.
- Never commit trained model artifacts, credentials, or local environment files.

## Pull requests

Describe the modeling change, expected effect, validation metrics, and any limitations. Do not present synthetic benchmark results as evidence of real-world underwriting performance.
